Updates

Forge looks for a new version shortly after it starts and shows an Update badge at the top of its window when there is one. Settings → Updates installs it:

  • .deb: Forge downloads the new package and shows the sudo apt install line to run, since a package install needs root.
  • AppImage: Forge replaces its own file once the sha256 matches; restart to run the new version.

Installed copies check https://forge.hostport.net/latest.json on their own; you change nothing.
